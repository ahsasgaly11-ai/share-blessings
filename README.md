# شارك النعم

منصة تبرع عيني في دولة قطر: مواد غذائية جافة، ملابس، أجهزة كهربائية، أثاث منزلي، وأغراض أخرى.
ثلاثة أطراف: المتبرّع، والمشرفون، والمستفيدون. كل طلب يمر على المشرفين قبل اعتماده.

## محتويات المستودع

| المسار | الوصف |
|---|---|
| `site/` | الموقع كاملًا. هذا المجلد هو ما يُنشر على الاستضافة. |
| `site/config.js` | بيانات الربط بـ Supabase (عنوان المشروع والمفتاح العام فقط). فارغ = نسخة تجريبية دون اتصال. |
| `supabase/setup.sql` | إعداد قاعدة البيانات: الجداول، أرقام الطلبات، صلاحيات الأدوار، تخزين الصور الخاص. |
| `supabase/team-accounts.sql` | تحديث لمشروع قائم: إنشاء حسابات الفريق من داخل الموقع (مضمَّن في setup.sql). |
| `supabase/site-settings.sql` | تحديث لمشروع قائم: جدول «إعدادات الموقع» وإيقاف الاستقبال من الخادم وتقدّم الحملات (مضمَّن في setup.sql). |
| `site/i18n/` | ملفات اللغات (الأردية، الفارسية، الهندية، الفلبينية، النيبالية، البنغالية، الإندونيسية). |
| `docs/setup-guide-ar.html` | دليل التشغيل خطوة بخطوة. |

## التشغيل باختصار

1. أنشئ مشروعًا في [Supabase](https://supabase.com) والصق `supabase/setup.sql` في SQL Editor ثم Run.
2. أوقف التسجيل الذاتي (Authentication ← Sign In / Providers) وأنشئ حسابك من Authentication ← Users.
3. ضع Project URL والمفتاح العام (Publishable key) في `site/config.js`.
4. انشر مجلد `site/` على Cloudflare Pages.
5. افتح الموقع ← المشرفون ← ادخل ← «اجعلني مدير المنصة».

التفاصيل الكاملة في `docs/setup-guide-ar.html`.

## النشر التلقائي من هذا المستودع (اختياري)

في Cloudflare: Workers & Pages ← Create ← Pages ← **Connect to Git** ← اختر هذا المستودع، واكتب في
**Build output directory** القيمة `site`، واترك أمر البناء فارغًا. بعدها كل تعديل يُرفع إلى المستودع يُنشر تلقائيًا.

## الأمان

- لا تضع المفتاح السري (`secret` أو `service_role`) في أي ملف داخل المستودع.
- المفتاح العام آمن: قاعدة البيانات تمنع الزوار من قراءة الجداول، ويستخدمون دوالًا محددة تعيد بياناتهم فقط.
- قاعدة البيانات ترفض تخطي أي خطوة في مسار الاعتماد.

## الأيقونات
الأيقونات صور ثلاثية الأبعاد واقعية مقدَّمة من صاحب المشروع. التفاصيل في `site/icons/CREDITS.txt`.

## اللغات
النص الأصلي بالعربية داخل `site/index.html`، والإنجليزية مضمّنة فيه. باقي اللغات في `site/i18n/<رمز>.json` (ur, fa, hi, fil, ne, bn, id)، ومفاتيح كل ملف هي النصوص العربية نفسها. عند إضافة نص عربي جديد للموقع أضِف ترجمته في كل ملف، وإلا يظهر بالعربية.

## إعدادات الموقع
يعدّل المدير من لوحة المشرفين ← «إعدادات الموقع»: رقم الواتساب والبريد، شريط الإعلان، فتح وإيقاف استقبال التبرعات والطلبات وكل صنف، أقسام الصفحة الرئيسية، الحملات وأهدافها، مناطق التغطية، أماكن التسليم، وأي نص في الموقع. ما يكتبه بالعربية يُترجم آليًا إلى كل اللغات عند الحفظ.
